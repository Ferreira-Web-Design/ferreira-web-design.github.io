# Ferreira Web Design

Site institucional da Ferreira Web Design — sites profissionais por assinatura.

## Estrutura
```
index.html        → página principal (funil AIDA: Atenção, Interesse, Desejo, Ação)
projetos/         → portfólio (cada trabalho abre em página própria)
```

## Antes de publicar
Abra `index.html`, procure `const WHATSAPP` e troque `5511999999999` pelo seu número (55 + DDD + número).

## Publicar no GitHub Pages
1. Crie um repositório (ex.: `ferreira-web-design`) e envie todos os arquivos desta pasta.
2. Vá em **Settings → Pages**, em *Source* escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
3. Em alguns minutos o site fica em `https://SEU-USUARIO.github.io/ferreira-web-design/`.
4. Para usar domínio próprio (.com.br), informe em **Settings → Pages → Custom domain** e marque **Enforce HTTPS**.
